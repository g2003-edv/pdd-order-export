# 拼多多订单自动导出工具（修复增强版）

基于「电商融」平台与拼多多商家后台的**多店铺订单自动导出工具**：
网页提交任务 → 服务器队列串行执行 → 真实浏览器自动登录（短信验证码自动回填）→
报表生成下载 → 文件自动归档。自带 Web 管理界面，支持多人协作、链接令牌保护、
Cloudflare / 自有服务器固定域名接入。

> 本仓库为**修复增强版**：在原版基础上修复了 7 个稳定性/正确性问题，详见下文。

## 功能特性

- **多店铺串行导出**：一次提交多家店铺，自动排队、自动跨店切换
- **全自动登录**：电商融账密自动登录（AJ-Captcha 滑块自动破解，可回退人工）、
  拼多多短信验证码自动从电商融短信记录抓取回填
- **Web 管理界面**：任务队列实时刷新、状态徽章、在线日志（已降噪）、
  文件下载/打包下载；使用人姓名与账号自动记忆
- **自动归档**：每次任务的报表按「任务编号」自动归档到独立目录
- **安全设计**：链接令牌保护（无密码模式）、密码加密存储、任务结束自动清理
  明文账号、已结束任务 24h 后自动清除
- **固定域名接入**：支持 Cloudflare Tunnel 或「自有服务器 + SSH 反向隧道 + nginx」
  两种方案（推荐后者，详见下文架构）

## 系统架构

```
同事浏览器（任何网络，https）
   ▼
固定入口（nginx 反代，TLS 终止）
   ▼  SSH 反向隧道 / Cloudflare Tunnel
本机 webui.py :8765（任务队列 + 令牌保护）
   ▼
pdd_export.py（Playwright）
   ├─ 电商融：登录 → 按店铺名查账号密码 → 抓取拼多多短信验证码
   └─ 真实 Chrome（CDP）：拼多多登录 → 查订单 → 生成报表 → 下载 CSV
```

## 修复清单（相对原版）

| # | 问题 | 修复 |
|---|------|------|
| 1 | 多店铺第 2 家起全部失败（收尾关闭全部标签页 → 浏览器退出） | 成功/失败路径均保活浏览器 |
| 2 | 拼多多「全部订单」标签被页面水合恢复为「待发货」→ 只导出未发货单 | 设置日期后二次点击标签并重设日期 |
| 3 | 报表下载 90s 超时直接放弃（报表生成慢必死） | 回到轮询重试，总时限 300s |
| 4 | 复用会话路径弹窗残留，后续店铺搜索点击 30s 连锁超时 | 每店强制重载商户页 + 关弹窗验证/ESC 兜底 |
| 5 | 电商融 AJ-Captcha 滑块需人工拖动 | OpenCV 模板匹配 + 拟人轨迹自动拖动（可回退人工） |
| 6 | 页面简陋、日志噪声大、任务列表无限堆积 | 全新界面 + 日志降噪 + 已结束任务 1h 隐藏 / 24h 清除 |
| 7 | 任务结束后浏览器窗口堆积任务栏；明文账号长期留存 | 任务结束自动关闭浏览器并清理凭据 |

## 部署

### 环境要求

- Windows 10/11 或 Server，Python 3.10+（已在 PATH）
- 已安装 Chrome（拼多多走真实浏览器 CDP 模式，风控最低）
- 可访问 `inner.example-dsr.com` 与 `mms.pinduoduo.com`

### 步骤

```bat
1. 解压本仓库到 D:\pdd_export_server（路径可改，脚本用相对定位）
2. 双击 安装环境.bat   （安装 Python 依赖 + Playwright Chromium）
3. 双击 启动公网访问.bat（临时公网地址试用）
```

生产建议（固定域名、开机自启、令牌保护、自动归档）见 `运维手册.md`
（随部署包附带，包含完整架构与故障排查表）。

> `cloudflared.exe` 未随仓库分发（体积 55MB）：
> 从 https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
> 下载 Windows x64 版放入部署目录。

### 可选依赖

- `pip install opencv-python` —— 启用电商融滑块自动破解
  （未安装时自动回退为人工拖动，不影响其他功能）

## 目录结构

```
pdd_export.py          导出机器人（登录/滑块/查单/报表/下载，含全部修复）
webui.py               Web 服务（Flask + 任务队列 + 界面）
config.yaml            平台地址等基础配置
requirements.txt       Python 依赖
run_webui.cmd          网页服务启动脚本（含令牌失效保护，供自启用）
tunnel_to_server.cmd   反向 SSH 隧道保活脚本（固定域名方案用）
安装环境.bat           首次安装依赖 + 浏览器内核
启动公网访问.bat        启动临时公网隧道（Cloudflare Quick Tunnel）
停止服务.bat            停止网页服务与隧道
start/stop_public.ps1  上述 .bat 对应的实现脚本
部署说明.txt            原厂说明（部分内容已被增强版取代）
```

## 安全说明

- `data/`（令牌、任务库、浏览器会话）**不入库**，已列入 `.gitignore`
- 请勿在公共场合泄露 `data/link_token.txt`；泄露后删除该文件并重启服务即可轮换
- 电商融密码仅在勾选「同时记住密码」时加密保存，且只对提交任务的那个浏览器可见
