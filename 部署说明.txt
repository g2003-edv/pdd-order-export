部署步骤
1. 解压到 D:\pdd_export_server，不要直接放在桌面。
2. 双击“安装环境.bat”，等待 Python 依赖和浏览器内核安装完成。
3. 双击“启动公网访问.bat”。
4. 窗口中会显示一条 https://....trycloudflare.com/ 基础地址（不再包含 token）。
5. 首次访问时在地址后附加一次 ?token=<data\link_token.txt 中的令牌>。
   浏览器会换取 HttpOnly Cookie 并跳转到不带 token 的地址，之后把基础地址发给同事即可。
6. 不要把带 token 的链接转发给他人；需要停止时，双击“停止服务.bat”。

要求
- Windows 10/11 或 Windows Server，已安装 Python 3.10+。
- 电脑需要安装 Edge 或 Chrome，并保持联网。
- 服务器电脑必须保持开机，不能睡眠，否则公网地址会断开。
- Cloudflare 临时地址在重新启动公网隧道后会变化，重新运行“启动公网访问.bat”即可获得新地址。
- 不要删除或分享 data\link_token.txt，它是链接保护令牌。
- 部署包不包含订单数据、账号、密码或登录状态。
